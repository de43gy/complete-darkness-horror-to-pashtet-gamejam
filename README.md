# Полная темнота (Complete Darkness)

Текстовый хоррор-лабиринт на Godot 4. Проект начат для 7-го Pashtet Game Jam
(https://itch.io/jam/pashtet-jam-7): тема — «Полная темнота», жанр — головоломка и/или хоррор.

Бездомная девочка, спасаясь от погони, забегает в тёмную пещеру и пробирается на ощупь вглубь
и вниз. Игрок не видит карту — только лог, где девочка описывает, что она делает, чувствует
и слышит.

**Состояние:** незавершённый прототип. Работают меню, генерация лабиринта, перемещение
и текстовый лог. Лабиринт пока отображается на экране — это отладочный вид.

## Запуск

Открыть `project.godot` в Godot 4.5 или новее и нажать F5.

## Управление

| Клавиши | Действие |
|---|---|
| Стрелки | Шаг на одну клетку |
| Shift + стрелка | Пощупать клетку рядом |
| Ctrl + стрелка | Топнуть |
| Пробел + стрелка | Прыгнуть через клетку |
| Enter на цифровой клавиатуре | Новый лабиринт (отладка) |
